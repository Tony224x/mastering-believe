# Solution — Notes orateur

> Module `12-notes-orateur` · Badge : **Orateur** · Lisible **sans coder**.

Les fichiers `.py` du même nom sont des **clés techniques optionnelles** (smoke tests).

## Easy (chemin principal)

### Notes sur 3 slides clés
Format : 3–5 mots-clés + 1 phrase de transition (pas un script lu).
Chrono cible : **6 min** pour l'ensemble.


## Medium (bonus)

### 5 questions pièges + réponses courtes
Génère avec l'IA, **filtre** ce qui est irréaliste, réécris 2 réponses.


## Hard (bonus)

### Oral chrono enregistré (ou chrono solo)
Notes 4 slides · 5 Q/R · auto-feedback 5 lignes.


## Clés structurées (rappel)

### easy

- **format** :
  - ouverture 10s
  - 2 details hors slide
  - transition
  - filet
- **opening_example** : Imaginez perdre chaque lundi une heure a retrouver vos entrees dans trois cahiers differents.

### medium

- **slides** :
  - accroche
  - solution
  - chiffres ou demande
- **questions_min** : 5
- **filter** : pas de chiffre absent du deck

### hard

- **duration_target_min** : 7
- **passes** : 2
- **scores** :
  - fluidite/5
  - clarte/5
