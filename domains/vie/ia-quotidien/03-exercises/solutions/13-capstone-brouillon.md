# Solution — Capstone brouillon

> Module `13-capstone-brouillon` · Badge : **Brouillon complet** · Lisible **sans coder**.

Les fichiers `.py` du même nom sont des **clés techniques optionnelles** (smoke tests).

## Easy (chemin principal)

Voici un exemple qui marche pour le **minimum J13** — un brouillon honnête, pas un deck parfait.

### Checklist minimum

- **8–10** slides **remplies** (pas titres seuls) — l’outline peut viser 10 titres
- Histoire problème → solution en **60 s** sans slides (chronomètre)
- Mention visible : « Brouillon v1 — à polir J14 »
- Aucune étude inventée · aucune donnée employeur réelle
- ≥ **3** trous identifiés (slide vide, preuve manquante, demande floue…)

### Fil 60 s (modèle)

1. Qui souffre (10 s)  
2. Solution en une phrase (10 s)  
3. Comment ça marche en 3 étapes (25 s)  
4. Demande claire (15 s)  


## Medium (bonus)

### Checklist anti-catastrophe (à cocher)

- [ ] pas d’étude inventée  
- [ ] pas de data employeur  
- [ ] titres = conclusions  
- [ ] fil 60 s fluide  
- [ ] label `fictif` sur les chiffres d’exemple  

Option : 1 slide chiffres **fictifs** si utile — sinon saute.


## Hard (bonus)

### Assemblage critique IA

Demande à ChatGPT (sans nouveaux chiffres inventés) :

| Partie | Contenu |
|--------|---------|
| Note /10 | cohérence globale |
| 5 faiblesses | concrètes, actionnables |
| 3 accroches | alternatives d’ouverture |

Puis liste max **7** tâches de polish pour J14 + journal IA (~12 lignes : généré / réécrit / refusé).
