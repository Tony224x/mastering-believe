# Solution — Slides & design sobre

> Module `11-slides-visuels` · Badge : **Slide zen** · Lisible **sans coder**.

Les fichiers `.py` du même nom sont des **clés techniques optionnelles** (smoke tests).

## Easy (chemin principal)

### 4 slides modèles
Chaque slide : **1 idée** · ≤ 3 puces · titre = conclusion · note « visuel : … ».
Référence visuelle : `assets/screens/screen-powerpoint-slide-sobre.png`


## Medium (bonus)

### Avant / après
Prends 2 slides denses, raccourcis à 3 puces, documente le delta.


## Hard (bonus)

### Kit design sobre
Palette limitée · hiérarchie titres · anti-mur de texte sur 6+ slides.


## Clés structurées (rappel)

### easy

- **before_title** : Solution
- **after_example** :
  - **title** : Un solde clair chaque lundi en 10 minutes
  - **bullets** :
    - Tableau unique entrees/sorties
    - 3 formules seulement
    - Routine IA pour expliquer les ecarts
  - **visual** : schema 3 blocs Lundi → Tableau → Decision

### medium

- **n_slides** : 4
- **max_bullets** : 3
- **iterations_min** : 1

### hard

- **style_rules_min** : 5
- **slides_min** : 6
- **fixes_min** : 3
