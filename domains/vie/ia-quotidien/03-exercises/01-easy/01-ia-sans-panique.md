# Mission J1 — Détecter une fausse assurance (easy)

> **Temps :** ~12 min · **Badge :** Détecteur de confiance

## Mission du jour

**But :** juger 3 affirmations **sans** dependre d un ChatGPT live instable.

### Réponse ChatGPT fictive (a analyser)

> « En 2025, 42 % des PME francophones utilisent l IA au quotidien (Rapport Invente Inc., 2025).  
> Le programme national Helix-IA a reduit de 18 % les erreurs comptables (Journal des Chiffres, mars 2025).  
> Selon Statistique Canada, 7 PME sur 10 prevoient un budget IA en 2026 (tableau 14-10-0000). »

## À faire

1. Remplis le tableau :

| Affirmation (courte) | Source citee | Ouvrable ? | Décision (utiliser / vérifier / jeter) |
|----------------------|--------------|------------|----------------------------------------|
| | | | |
| | | | |
| | | | |

2. Coche **au moins une** décision « jeter » ou « vérifier ».
3. Ecris 2 phrases : ce que ça change pour toi.

## Indice
Une source avec un titre trop parfait + un % rond = signal d alerte.

## Réussite
- [ ] 3 lignes de tableau
- [ ] ≥1 refus ou vérification
- [ ] 2 phrases personnelles
- [ ] Aucune donnée sensible

## Feedback
Si tu as jete au moins une affirmation inventée : **badge Détecteur de confiance débloque.** Bravo.
