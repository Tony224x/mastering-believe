# Mission J1 — Detecter une fausse assurance (easy)

> **Temps :** ~12 min · **Badge :** Detecteur de confiance

## Mission du jour

**But :** juger 3 affirmations **sans** dependre d un ChatGPT live instable.

### Reponse ChatGPT fictive (a analyser)

> « En 2025, 42 % des PME francophones utilisent l IA au quotidien (Rapport Invente Inc., 2025).

> Selon Statistique Canada, 7 PME sur 10 prevoient un budget IA en 2026 (tableau 14-10-0000). »

## A faire

1. Remplis le tableau :

| Affirmation (courte) | Source citee | Ouvrable ? | Decision (utiliser / verifier / jeter) |
|----------------------|--------------|------------|----------------------------------------|
| | | | |
| | | | |

2. Coche **au moins une** decision « jeter » ou « verifier ».
3. Ecris 2 phrases : ce que ca change pour toi.

## Indice
Une source avec un titre trop parfait + un % rond = signal d alerte.

## Reussite
- [ ] 3 lignes de tableau
