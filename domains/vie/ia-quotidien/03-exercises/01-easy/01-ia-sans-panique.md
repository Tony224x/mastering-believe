# Mission J1 — Détecter une fausse assurance (easy)

> **Temps :** ~12 min · **Badge :** Détecteur de confiance

## Mission du jour

**But :** juger 3 affirmations **sans** dépendre d’un ChatGPT live instable.

### Réponse ChatGPT fictive (à analyser)

> « En 2025, 42 % des PME francophones utilisent l’IA au quotidien (Rapport Invente Inc., 2025).  
> Le programme national Helix-IA a réduit de 18 % les erreurs comptables (Journal des Chiffres, mars 2025).  
> Selon Statistique Canada, 7 PME sur 10 prévoient un budget IA en 2026 (tableau 14-10-0000). »

## À faire

1. Remplis le tableau :

| Affirmation (courte) | Source citée | Ouvrable ? | Décision (utiliser / vérifier / jeter) |
|----------------------|--------------|------------|----------------------------------------|
| | | | |
| | | | |
| | | | |

2. Coche **au moins une** décision « jeter » ou « vérifier ».
3. Écris 2 phrases : ce que ça change pour toi.

## Indice
Un titre inhabituel ou un pourcentage « trop rond » peut **donner envie** de vérifier — ce n’est pas une preuve. Ouvre la source citée et vérifie qu’elle soutient **exactement** l’affirmation avant de l’utiliser.

## Réussite
- [ ] 3 lignes de tableau
- [ ] ≥1 refus ou vérification
- [ ] 2 phrases personnelles
- [ ] Aucune donnée sensible

## Feedback
Si tu as jeté au moins une affirmation inventée : **badge Détecteur de confiance débloqué.** Bravo.
