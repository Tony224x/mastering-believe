# Plan figé domaine ia-quotidien

Brief Phase 0 : formation entrepreneuriat / PME, débutant·e IA, ~45 min/jour, outils ChatGPT + Excel + PowerPoint. Capstone = deck pitch 8–12 slides. Projet secondaire = trésorerie/budget PME fictif. Codex = bonus hors chemin critique. Données réelles employeur / association interdites.

---

## J1 — IA sans panique
- **Concepts clés** : LLM = prédiction de texte ; ce que l'IA fait / ne fait pas ; perroquet stochastique ; usage basique vs usage pro
- **Acquis** : expliquer en 3 phrases ce qu'est ChatGPT et pourquoi « elle a l'air sûre d'elle » n'implique pas la vérité
- **Sources autorisées** : Stochastic Parrots 2021 ; GPT-4 System Card ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT (compte gratuit ou Plus)
- **Slug** : `01-ia-sans-panique`

## J2 — Prompts qui marchent
- **Concepts clés** : rôle + contexte + tâche + format + contraintes ; exemples few-shot ; itération
- **Acquis** : écrire 3 prompts réutilisables (réflexion, Excel, slides) avec structure complète
- **Sources autorisées** : OpenAI Prompting Guide ; Mollick Assigning AI
- **Stack du jour** : ChatGPT
- **Slug** : `02-prompts-qui-marchent`

## J3 — Hallucinations & vérification
- **Concepts clés** : hallucination ; checklist SIFT-like légère ; données sensibles ; CNIL/OPC
- **Acquis** : détecter une invention plausible et appliquer une checklist avant d'utiliser une réponse pour l'école/le travail
- **Sources autorisées** : GPT-4 System Card ; CNIL IA ; NIST AI RMF
- **Stack du jour** : ChatGPT + navigateur
- **Slug** : `03-hallucinations-vérification`

## J4 — Partenaire de réflexion
- **Concepts clés** : tuteur socratique ; devil's advocate ; cadrage décision ; retrieval (ne pas consommer passif)
- **Acquis** : mener une session de 15 min qui clarifie un choix de carrière ou d'études sans se faire « donner la réponse »
- **Sources autorisées** : Mollick 2023 ; Bloom 1984 ; Dunlosky 2013
- **Stack du jour** : ChatGPT
- **Slug** : `04-partenaire-réflexion`

## J5 — Écrire avec l'IA (Word / rapports)
- **Concepts clés** : brouillon → structure → ton → relecture humaine ; paraphraser vs triche ; bibliographie
- **Acquis** : produire un plan + 1 page de rapport formation avec IA, puis réécrire 30 % de sa main
- **Sources autorisées** : Mollick 2023 ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT + Word (ou Google Docs)
- **Slug** : `05-ecrire-avec-ia`

## J6 — Excel + IA : les bases
- **Concepts clés** : décrire un tableau à ChatGPT ; demander formules en langage naturel ; copier/coller sûr ; erreurs #REF! #DIV/0!
- **Acquis** : à partir d'une description, obtenir et appliquer 3 formules correctes dans un classeur fictif
- **Sources autorisées** : Microsoft formulas overview ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `06-excel-bases-ia`

## J7 — Formules, tableaux croisés & modèles
- **Concepts clés** : SOMME/SI/RECHERCHEV ou XLOOKUP ; tableau structuré ; hypothèse « et si »
- **Acquis** : construire un mini-modèle (recettes / dépenses / solde) avec formules expliquées ligne par ligne par l'IA
- **Sources autorisées** : Microsoft formulas ; Few Show Me the Numbers
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `07-formules-tableaux`

## J8 — Nettoyer, analyser, visualiser
- **Concepts clés** : données sales ; dédoublonnage ; graphiques sobres ; pièges des camemberts inutiles
- **Acquis** : transformer une liste « sale » fictive en tableau propre + 1 graphique lisible, documenté avec l'IA
- **Sources autorisées** : Few 2012 ; Microsoft Excel support
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `08-nettoyer-analyser`

## J9 — Projet secondaire : trésorerie / budget PME
- **Concepts clés** : flux de trésorerie simple ; budget mensuel ; scénario base/optimiste/pessimiste ; confidentialité
- **Acquis** : livrer un classeur **fictif** « Budget PME Demo » réutilisable (onglets, formules, résumé 5 lignes)
- **Sources autorisées** : NIST AI RMF (risque données) ; CNIL ; Microsoft Excel
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `09-projet-trésorerie`

## J10 — Structure d'un pitch qui tient
- **Concepts clés** : problème → solution → preuve → appel ; SUCCESs (Heath) ; audience jury formation vs employeur
- **Acquis** : outline 8–12 slides validée (titres seuls) pour le capstone
- **Sources autorisées** : Duarte Resonate ; Heath Made to Stick
- **Stack du jour** : ChatGPT
- **Slug** : `10-structure-pitch`

## J11 — Slides & design sobre
- **Concepts clés** : une idée / slide ; hiérarchie visuelle ; prompts de génération de contenu slide-ready ; anti-mur de texte
- **Acquis** : rédiger le contenu de 4 slides « modèles » (titre, bullets courts, note visuel) avec l'IA
- **Sources autorisées** : Reynolds Présentation Zen ; Duarte Resonate
- **Stack du jour** : ChatGPT + PowerPoint
- **Slug** : `11-slides-visuels`

## J12 — Notes orateur & répétition
- **Concepts clés** : notes orateur ≠ lire les slides ; chrono 5–8 min ; questions pièges
- **Acquis** : notes orateur pour 3 slides clés + 5 questions/réponses anticipées générées puis filtrées
- **Sources autorisées** : Reynolds Présentation Zen ; Mollick 2023
- **Stack du jour** : ChatGPT + PowerPoint
- **Slug** : `12-notes-orateur`

## J13 — Capstone brouillon : deck pitch v1
- **Concepts clés** : assemblage bout-en-bout ; cohérence narrative ; sources inventées interdites ; checklist qualité
- **Acquis** : brouillon complet 8–12 slides (contenu) d'un pitch PME/innovation type formation, produit avec ChatGPT
- **Sources autorisées** : Duarte ; Heath ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT + PowerPoint
- **Slug** : `13-capstone-brouillon`

## J14 — Capstone final : deck pitch livrable
- **Charge** : 1–2 soirs ; **minimum** = 8 slides + notes 3 slides + journal 5 puces ; reste = bonus
- **Concepts clés** : polish ; vérification faits ; relecture à voix haute ; portfolio ; suite Excel
- **Acquis** : **deck PowerPoint final 8–12 slides** présentable + résumé 1 page « comment j'ai utilisé l'IA » + classeur trésorerie en annexe si pertinent
- **Sources autorisées** : ensemble des refs A–D
- **Stack du jour** : ChatGPT + PowerPoint (+ Excel annexe)
- **Slug** : `14-capstone-deck-pitch`
