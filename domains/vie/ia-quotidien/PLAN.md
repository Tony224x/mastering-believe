# Plan fige domaine ia-quotidien

Brief Phase 0 : technicienne comptable + certificat HEC Entrepreneuriat/PME, debutante IA, ~45 min/jour, outils ChatGPT + Excel + PowerPoint. Capstone = deck HEC 8–12 slides. Projet secondaire = tresorerie/budget PME fictif. Codex = bonus hors chemin critique. Donnees reelles ONG interdites.

---

## J1 — IA sans panique
- **Concepts cles** : LLM = prediction de texte ; ce que l'IA fait / ne fait pas ; perroquet stochastique ; usage basique vs usage pro
- **Acquis** : expliquer en 3 phrases ce qu'est ChatGPT et pourquoi "elle a l'air sure d'elle" n'implique pas la verite
- **Sources autorisees** : Stochastic Parrots 2021 ; GPT-4 System Card ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT (compte gratuit ou Plus)
- **Slug** : `01-ia-sans-panique`

## J2 — Prompts qui marchent
- **Concepts cles** : role + contexte + tache + format + contraintes ; exemples few-shot ; iteration
- **Acquis** : ecrire 3 prompts reutilisables (reflexion, Excel, slides) avec structure complete
- **Sources autorisees** : OpenAI Prompting Guide ; Mollick Assigning AI
- **Stack du jour** : ChatGPT
- **Slug** : `02-prompts-qui-marchent`

## J3 — Hallucinations & verification
- **Concepts cles** : hallucination ; checklist SIFT-like legere ; donnees sensibles ; CNIL/OPC
- **Acquis** : detecter une invention plausible et appliquer une checklist avant d'utiliser une reponse pour l'ecole/le travail
- **Sources autorisees** : GPT-4 System Card ; CNIL IA ; NIST AI RMF
- **Stack du jour** : ChatGPT + navigateur
- **Slug** : `03-hallucinations-verification`

## J4 — Partenaire de reflexion
- **Concepts cles** : tuteur socratique ; devil's advocate ; cadrage decision ; retrieval (ne pas consommer passif)
- **Acquis** : mener une session de 15 min qui clarifie un choix de carriere ou d'etudes sans se faire "donner la reponse"
- **Sources autorisees** : Mollick 2023 ; Bloom 1984 ; Dunlosky 2013
- **Stack du jour** : ChatGPT
- **Slug** : `04-partenaire-reflexion`

## J5 — Ecrire avec l'IA (Word / rapports)
- **Concepts cles** : brouillon → structure → ton → relecture humaine ; paraphraser vs triche ; bibliographie
- **Acquis** : produire un plan + 1 page de rapport HEC-like avec IA, puis reecrire 30 % de sa main
- **Sources autorisees** : Mollick 2023 ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT + Word (ou Google Docs)
- **Slug** : `05-ecrire-avec-ia`

## J6 — Excel + IA : les bases
- **Concepts cles** : decrire un tableau a ChatGPT ; demander formules en langage naturel ; copier/coller sur ; erreurs #REF! #DIV/0!
- **Acquis** : a partir d'une description, obtenir et appliquer 3 formules correctes dans un classeur fictif
- **Sources autorisees** : Microsoft formulas overview ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `06-excel-bases-ia`

## J7 — Formules, tableaux croises & modeles
- **Concepts cles** : SOMME/SI/RECHERCHEV ou XLOOKUP ; tableau structure ; hypothese "et si"
- **Acquis** : construire un mini-modele (recettes / depenses / solde) avec formules expliquees ligne par ligne par l'IA
- **Sources autorisees** : Microsoft formulas ; Few Show Me the Numbers
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `07-formules-tableaux`

## J8 — Nettoyer, analyser, visualiser
- **Concepts cles** : donnees sales ; dedoublonnage ; graphiques sobres ; pieges des camemberts inutiles
- **Acquis** : transformer une liste "sale" fictive en tableau propre + 1 graphique lisible, documente avec l'IA
- **Sources autorisees** : Few 2012 ; Microsoft Excel support
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `08-nettoyer-analyser`

## J9 — Projet secondaire : tresorerie / budget PME
- **Concepts cles** : flux de tresorerie simple ; budget mensuel ; scenario base/optimiste/pessimiste ; confidentialite
- **Acquis** : livrer un classeur **fictif** "Budget PME Demo" reutilisable (onglets, formules, resume 5 lignes)
- **Sources autorisees** : NIST AI RMF (risque donnees) ; CNIL ; Microsoft Excel
- **Stack du jour** : ChatGPT + Excel
- **Slug** : `09-projet-tresorerie`

## J10 — Structure d'un pitch qui tient
- **Concepts cles** : probleme → solution → preuve → appel ; SUCCESs (Heath) ; audience HEC vs ONG
- **Acquis** : outline 8–12 slides validee (titres seuls) pour le capstone
- **Sources autorisees** : Duarte Resonate ; Heath Made to Stick
- **Stack du jour** : ChatGPT
- **Slug** : `10-structure-pitch`

## J11 — Slides & design sobre
- **Concepts cles** : une idee / slide ; hierarchie visuelle ; prompts de generation de contenu slide-ready ; anti-mur de texte
- **Acquis** : rediger le contenu de 4 slides "modeles" (titre, bullets courts, note visuel) avec l'IA
- **Sources autorisees** : Reynolds Presentation Zen ; Duarte Resonate
- **Stack du jour** : ChatGPT + PowerPoint
- **Slug** : `11-slides-visuels`

## J12 — Notes orateur & repetition
- **Concepts cles** : notes orateur ≠ lire les slides ; chrono 5–8 min ; questions pieges
- **Acquis** : notes orateur pour 3 slides cles + 5 questions/reponses anticipees generees puis filtrees
- **Sources autorisees** : Reynolds Presentation Zen ; Mollick 2023
- **Stack du jour** : ChatGPT + PowerPoint
- **Slug** : `12-notes-orateur`

## J13 — Capstone brouillon : deck HEC v1
- **Concepts cles** : assemblage bout-en-bout ; coherence narrative ; sources inventees interdites ; checklist qualite
- **Acquis** : brouillon complet 8–12 slides (contenu) d'un pitch PME/innovation HEC-like, produit avec ChatGPT
- **Sources autorisees** : Duarte ; Heath ; OpenAI Prompting Guide
- **Stack du jour** : ChatGPT + PowerPoint
- **Slug** : `13-capstone-brouillon`

## J14 — Capstone final : deck HEC livrable
- **Concepts cles** : polish ; verification faits ; relecture a voix haute ; portfolio ; suite Excel
- **Acquis** : **deck PowerPoint final 8–12 slides** presentable + resume 1 page "comment j'ai utilise l'IA" + classeur tresorerie en annexe si pertinent
- **Sources autorisees** : ensemble des refs A–D
- **Stack du jour** : ChatGPT + PowerPoint (+ Excel annexe)
- **Slug** : `14-capstone-deck-hec`
